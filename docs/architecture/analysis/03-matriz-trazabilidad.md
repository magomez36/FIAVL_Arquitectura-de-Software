Cada fila funcional corresponde a un objetivo del actor. Una historia puede aportar tanto un caso como restricciones de una vista. Por ejemplo, Spec 6 US5 exige comprobar concurrencia y persistencia dentro del objetivo de reservar plazas, y Spec 1 FR-007–009 describe la infraestructura de desarrollo. Los requisitos sin identificador numerado se trazan con sus nombres de historia o criterios de éxito. El [catálogo detallado](02-actores-y-casos-de-uso.md) conserva precondiciones, alternativas, persistencia y pruebas para cada caso.
