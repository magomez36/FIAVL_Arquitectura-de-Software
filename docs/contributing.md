# Contribuir y entregar

1. Confirmar propietario y rama en AGENTS.md. Leer constitución, contratos y roadmap.
2. Especificar una historia verificable, generar plan y tareas con Spec Kit 1.4.3, analizar cobertura y resolver cuestiones de alcance con el responsable.
3. Crear pruebas de aceptación antes de implementar. Respetar formas JSON, fechas, claves de navegador y migraciones por archivo.
4. Ejecutar la secuencia del README desde una copia limpia. Para cambios de UI, probar teclado, ancho móvil y estados de error y vacío.
5. Revisar git status y diff. Entregar resultados de cada comando, pruebas omitidas y razón. La publicación y la decisión de integrar corresponden al integrante y a Manuel.
