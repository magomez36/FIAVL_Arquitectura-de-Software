# Verificación

Desde raíz en Windows ejecutar `.\fiavl.cmd check` con los puertos libres. Para inspección local ejecutar `.\fiavl.cmd`. Abrir / a 1440 y 375 px, accionar las láminas y repetir con movimiento reducido. En /opiniones enviar una valoración y consultar el resumen tras recargar. El E2E usa SQLite temporal. La encuesta de la aplicación normal escribe en la base local configurada.

Para reproducir el autoavance, abrir / con movimiento normal, apartar el puntero del hero y dejar el foco fuera de sus controles. Con la pestaña visible, la barra dorada completa un ciclo de siete segundos. Repetir con movimiento reducido desde las herramientas del navegador. Comprobar las referencias de «Guía FIAVL 2026», abrir las cinco sedes documentadas y comparar con la sección «Directorio demo».
